# 운영체제 (Operating Systems)

동아대학교 컴퓨터공학과 · 3학년 수업 과제 · C · Ubuntu

운영체제의 프로세스·스레드, 상호배제, CPU 스케줄링, 페이지 교체 알고리즘을 C로 구현했습니다.

## 과제 목록

| 과제 | 주제 | 내용 |
|---|---|---|
| HW1 | 멀티 프로세스 | 싱글 프로세스와 멀티 프로세스(8개, 10개)로 1부터 1000까지 7씩 더해 출력 |
| HW2 | 멀티 프로세스 · 스레드 | 싱글 프로세스, 멀티 프로세스, 멀티 스레드로 구간(1–25, 26–50, 51–75, 76–100)마다 3, 5, 7, 9를 곱해 출력 |
| HW3 | 상호배제 | Dekker, Peterson, Dijkstra, Semaphore |
| HW4 | CPU 스케줄링 1 | FCFS, SJF (선점 · 비선점) |
| HW5 | CPU 스케줄링 2 | 비선점 우선순위(NPP), 선점 우선순위(PP), 라운드 로빈(RR). 간트 차트 출력 버전과 멀티 스레드 버전을 각각 작성 |
| HW6 | CPU 스케줄링 3 | MLFQ, HRN |
| HW7 | 페이지 교체 | FIFO, OPT (LRU, Clock은 구현하지 못함) |
